# fo4-regalia-of-mystery

A Fallout 4 mod that brings the Fallout 76 Order of Mysteries set to the Commonwealth as a small espionage and assassin loadout, tuned for Survival Mode. Plugin: `RegaliaOfMystery.esl`.

This repo holds the agreed intent and the specs for what we are building or have built. No brainstorming lives here. Open items are fine; when we drift or learn something, the spec is updated so it stays true.

## Specs (`spec/`)

- [`spec-regalia.md`](spec/spec-regalia.md): decisions for the whole plugin (name, discovery, crafting station, instructions).
- [`spec-blade-of-bastet.md`](spec/spec-blade-of-bastet.md): the first item (version 0.1).

The overall concept is still being fleshed out elsewhere and is not kept here; each spec below is self-contained.

## Status

Pre-0.1: planning. Nothing is built yet. Open items are listed at the end of each spec.
